EINMALIG EINRICHTEN
-------------------
1. Supabase → SQL Editor → wartungsplanung_supabase_komplett.sql einfügen
   und ausführen. Das Skript ist mehrfach ausführbar und ändert keine Daten.
   Am Ende erscheint eine Liste mit neun Tabellen, jede mit rls = true
   und genau einer Policy.

2. Die Anmeldung ist dieselbe wie bei Meldungen und Lagerchemie: gleiches
   Projekt, gleiche Nutzer, gleiches Passwort. Wer dort hineinkommt, kommt
   auch hier hinein. Es muss niemand neu angelegt werden.

3. Daten übernehmen (nur beim Umstieg von der lokalen Fassung):
   In der lokalen App unter "Daten" den Knopf
   "Stammdaten als SQL für Supabase" drücken und die erzeugte Datei
   im SQL Editor ausführen.


HOCHLADEN
---------
Alle Dateien in denselben Ordner legen — die Pfade im HTML sind relativ,
es ist egal, in welchem Unterordner die App liegt. Weil die App
index.html heisst, genuegt der Ordnerlink:
  https://<deine-seite>/wartungsplanung_V4/

Die beiden Textdateien (diese hier und die SQL) sind bei GitHub Pages
oeffentlich abrufbar. Geheim ist daran nichts, aber wenn du den
Tabellenaufbau nicht im Netz haben willst, leg die SQL eine Ebene
hoeher statt in den ausgelieferten Ordner.

Die App muss über https ausgeliefert werden, sonst läuft der Service
Worker nicht und "Zum Startbildschirm hinzufügen" fehlt.


BEI JEDER NEUEN VERSION
-----------------------
Drei Stellen hochzählen, sonst merken die Geräte das Update nicht:

  1. sw_wartungsplanung.js   const CACHE = 'wartungsplanung-v4'
  2. index.html              const APP_VERSION = 'V4'  (eine Stelle)
  3. index.html              <title>, der Zusatz neben dem Logo und die
                             Zahl auf dem Anmeldebildschirm (drei Stellen)
  4. der Name des Ordners und der ZIP

Am wichtigsten ist Punkt 1: bleibt der Cache-Name gleich, laden die Geraete
weiter die alte Fassung aus ihrem Speicher und das Update-Banner erscheint
nie, egal was hochgeladen wurde.

Die Versionsnummer steht oben im Kopf neben "Wartungs Planung", im
Browser-Tab und auf dem Anmeldebildschirm. So sieht man auf jedem Gerät
sofort, welcher Stand läuft.

Nach dem Hochladen bekommen alle, die die App offen haben, unten ein
Banner "Neue Version verfügbar" mit dem Knopf "Jetzt aktualisieren".
Erst wenn jemand ihn drückt, wird umgestellt — niemand verliert mitten
im Planen seinen Bildschirm.
